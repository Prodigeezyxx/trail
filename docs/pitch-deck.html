THE PROBLEM

Information without action
is just noise.

Access to rights, services and opportunity depends on being able to find information you understand and trust. In many African communities that information is:

  • Fragmented across offices, formats and languages
  • Out of date, with no way to tell from what's current
  • Hard to verify — source, date and limits all unstated
  • Locked behind systems that are hard to navigate

TOP-DOWN: TRAILS

  • Last-checked date (not assumed current)
  • Explicit limitations (required field)
  • Separate confidence & importance scores
  • Named holder + witness
  • The exact question to ask

HOW GRADUATION WORKS

1 Resident raises an issue with no votes
2 At 3 votes → community-verified
3 At 5 votes → can be promoted to official trail with holder + date

Votes are local. Without a relay, nobody else sees them. Every issue card says so.

PROVENANCE RULES THE CODE ENFORCES

Five rules, never broken.

①

A source is never shown as verified unless it is.

Every record carries an explicit verified flag. 0 of 14 seeded records are marked independently checked — stated in the UI.

②

"Unchecked" is distinct from "stale".

Freshness is computed against each source's own cadence. An annual report is not stale at 40 days.

③

Limitations are a required field.

Every record states what it does not tell you, shown before the next step.

④

Confidence and importance are separate.

How much a thing matters and how much it can be trusted are different questions.

⑤

A gap never becomes a claim.

Where a value is unknown the UI says unknown. Where there is no URL it says "No URL".

WHAT IS NOT BUILT

Stated so nobody has to discover it.

No server

Votes and issues cannot sync between devices.

No live data

Snapshot dated 21 Sep 2026. Nothing polls.

No encryption

Local storage is readable by anyone with device access.

No referral DB

Report routes by category, not to a verified, country-specific org list.

Share buttons

Need a connection (hand text to an app).

Anonymity not implied

No state-run mechanism confirmed to accept anonymous submissions.
